# 📘 Sobre o Projeto
O projeto visa auxiliar o grupo Dantai Fênix em sua rotina diária - gerenciamento de integrantes, gerenciamento  de treinos, logistica de
instrumentos , logistica de apresentações e repertório de musicas - por meio de uma aplicação web.

Seu intuito é ser util para todos os integrantes do grupo independente de seus cargos e posições hierárquicas, e também, ser um site
institucional para aqueles que querem saber mais sobre o grupo.

A criação desse projeto veio por meio de uma grande dificuldade dada na hora de realizar o controle das atividades do grupo, e a falta
de representatividade fora das redes socias, nascendo assim a ideia de uma aplicação web multiusuário que facilita o dia a dia além de documentar seus registros.

# 🎯 Funcionalidade
### 👤 Usuário Comum (Integrante)
- Visualização de treinos
- Pendências e mensalidades
- Feedbacks individuais
- Informações pessoais e do grupo
- Agenda de apresentações e tarefas


### 🔐 Administrador
- Gestão de integrantes
- Cadastro e organização de músicas e repertórios
- Logística de instrumentos
- Controle de apresentações e escala de tocadores


### 🌐 Site Institucional
- Apresentação do grupo Dantai Fênix
- Informações sobre história, missão e valores
- Agenda de apresentações e eventos
- Galeria de fotos e vídeos
- Contato e redes sociais

# ⚙️ Instalação
### Pré-requisitos
- Node.js instalado
- MySQL ativo
- Editor de código (ex: VS Code)

1. Clone o repositório
2. Instale as dependências
3. Inicie o servidor

```bash
  git clone https://github.com/GouveiaGSilva/Sistema-DantaFenix.git
  cd Sistema-DantaFenix
  npm install
  npm start
````

# 📝 Prefixos de Commits

* `DOCS:` Arquivos de documentação (`README.md`, `LICENSE`, comentários explicativos, etc.)
* `FIX:` Correções de bugs e falhas no sistema
* `FEAT:` Implementação de nova funcionalidade
* `STYLE:` Alterações visuais no código: identação, espaços, organização de blocos, sem mudar funcionalidade
* `REFATOR:` Melhorias no código sem alterar o comportamento (limpeza, simplificação de lógicas)
* `TEST:` Criação ou modificação de testes (unitários, integração, mocks etc.)
* `CHORE:` Tarefas administrativas e de manutenção (atualizar libs, limpar arquivos, renomear pastas, etc.)
