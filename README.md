
# Sistema de Controle de Grupo : Dantai Fênix


O projeto visa auxiliar o grupo Dantai Fênix em sua rotina diária - gerenciamento de integrantes, gerenciamento  de treinos, logistica de
instrumentos , logistica de apresentações e repertório de musicas - por meio de uma aplicação web.

Seu intuito é ser util para todos os integrantes do grupo independente de seus cargos e posições hierarquicas, e também, ser um site
institucional para aqueles que querem saber mais sobre o grupo.

A criação desse projeto veio por meio de uma grande dificuldade dada na hora de realizar o controle das atividades do grupo, e a falta
de representatividade fora das redes socias, nascendo assim a idéia de uma aplicação web multiusuário que facilita o dia a dia além de documentar seus registros.

# Semântica de Commits

* `DOCS:` Arquivos de documentação (`README.md`, `LICENSE`, comentários explicativos, etc.)
* `DADOS:` Alterações relacionadas a banco de dados
* `FIX:` Correções de bugs e falhas no sistema
* `FEAT:` Implementação de nova funcionalidade
* `PAGINA:` Criação ou modificação de páginas, layout ou conteúdo visível no front-end
* `ROTA:` Adição ou alteração de rotas no servidor (Express)
* `SESSAO:` Lógica de login, logout, sessões e autenticação (express-session)
* `MIDDLEWARE:` Criação ou ajuste de middlewares (ex: controle de acesso, validação)
* `AJUSTE:` Pequenas alterações visuais, de texto ou organização geral (sem alterar lógica)
* `INFRA:` Configuração de estrutura do projeto, package.json, app.listen, pastas, scripts de inicialização
* `SEGURANCA:` Controle de permissões, filtros de acesso, validações extras
* `STYLE:` Alterações visuais no código: identação, espaços, organização de blocos, sem mudar funcionalidade
* `REFATOR:` Melhorias no código sem alterar o comportamento (limpeza, simplificação de lógicas)
* `BUILD:` Ajustes no processo de build, como empacotamento ou dependências de produção
* `TESTE:` Criação ou modificação de testes (unitários, integração, mocks etc.)
* `CHORE:` Tarefas administrativas e de manutenção (atualizar libs, limpar arquivos, renomear pastas, etc.)
